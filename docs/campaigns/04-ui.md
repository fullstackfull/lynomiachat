# Lynomia Campaigns: the builder

Chatwoot's campaign forms, extended; no new page.

## 1. Recipients

`components-next/Campaigns/Pages/CampaignPage/CampaignRecipients.vue`, used by `WhatsAppCampaignForm.vue` and
`SMSCampaignForm.vue` where the label picker was:

| | |
|---|---|
| **Recipients** (legend) | |
| Labels | the existing labels multi-select (`TagMultiSelectComboBox`) |
| Shared audiences | the account's **shared** contact audiences only (personal filters are not offered; the API refuses them anyway). Empty state: "No shared audiences yet. Save a contact filter as a shared audience in Contacts." |
| Count | "{count} contacts match now. Each contact receives the campaign once, and recipients are selected again when it is sent." |

- At least one label or shared audience is required ("Select at least one label or shared audience").
- Submit sends `audience: buildCampaignAudience(labelIds, audienceIds)` (`shared/constants/campaign.js`):
  `[{ id, type: 'Label' }…, { id, type: 'Audience' }…]`.
- The audiences come from the `customViews` store the sidebar already loads; nothing is fetched twice.
- One-off campaigns still cannot be edited after creation (Chatwoot); they can be deleted, which also releases their
  audiences ([03](03-audience-dependency.md)).

## 2. The count

- `CampaignsAPI.audiencePreview(audience, { signal })` → `POST /campaigns/audience_preview` ([05](05-preview-and-dedup.md)).
- Debounced (300 ms); the shared `useAbortableRequest` cancels a superseded request, so a slow answer never overwrites a
  newer one.
- While counting: "Counting matching contacts…". On failure: "The number of matching contacts could not be loaded." —
  unknown, **never shown as 0**.
- No contact list, names or sample in the form: the audience opens in Contacts for that.

## 3. Language and layout

- Strings in `campaign.json` (`CAMPAIGN.RECIPIENTS`), English and Arabic; the old label-only `…FORM.AUDIENCE` strings
  were removed from both. The audience-in-use note in `contactFilters.json`.
- Tailwind utilities and design-system text classes only; logical properties (RTL renders mirrored).
- Screenshots (`docs/campaigns/screenshots/`): the recipients block in English and Arabic, at phone width, the campaign
  list, the audience-in-use note and the refused deletion ([07](07-e2e.md)).
