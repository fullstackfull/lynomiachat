## REUSED / EXTENDED / NEW / NOT CREATED / DEFERRED

**REUSED, unchanged:** the Cloud and 360dialog provider services' send paths; `Whatsapp::TemplatesSyncSchedulerJob`; `Whatsapp::SendOnWhatsappService`; `Whatsapp::PopulateTemplateParametersService`; the per-inbox template endpoint; `Flows::Template.sendable?` and `isSendableTemplate`; `Flows::TemplateValidator`; `Flows::Nodes::SendTemplate`; the campaign runtime; `CsatTemplateNameService` and the CSAT lifecycle; the `audited` gem and `Enterprise::AuditLog`; Pundit; `components-next/*`.

**EXTENDED:** `Whatsapp::Providers::WhatsappCloudService#sync_templates` (mirror after sync, via the `custom/` overlay); `Webhooks::WhatsappEventsJob` (a template branch, via the `custom/` overlay); `Whatsapp::WebhookSetupService` and `Whatsapp::FacebookApiClient` (one subscribed field added); `Webhooks::WhatsappController` (an app-level route beside the per-channel one); `Whatsapp::TemplateProcessorService` (the sendability fix); `WhatsAppCampaignForm.vue` (the dropdown key); `CallToActionTemplate.vue` (header and footer); `ContactDrop` (`phone`); the templates settings page (list → manager).

**NEW, justified primitive:** exactly one — the `whatsapp_message_templates` table and `Whatsapp::MessageTemplate`, with the services around it (`Mirror`, `Query`, `Actions`, `Validator`, `Submission`, `Revision`, `Removal`, `Duplication`, `StatusUpdate`, `MetaClient`, `Error`, `Components`, `Operation`), one controller, one policy, three jbuilder views, one API module and the manager UI. Justification in item 8.

**NOT CREATED:** a second WhatsApp provider, sender, template delivery engine, Meta credential store, campaign engine, flow template sender, webhook receiver, authorization model, audit system, versioning scheme, polling job, template marketplace or user-shared starter library.
